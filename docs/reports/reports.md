# Reports

The ERPNext Incentive Compensation Engine provides reports for analyzing calculated commissions across payees, plans, rules, invoices, and dates.

These reports are read-only views of Commission Ledger data. They help administrators understand how commissions were calculated and provide visibility into commission activity.

## Available Reports

The application provides six commission reports:

| Report                | Answers                                                    |
| --------------------- | ---------------------------------------------------------- |
| Commission Summary    | How much commission was generated overall?                 |
| Commission by Payee   | How much commission did each payee earn?                   |
| Commission by Plan    | How much commission was generated by each commission plan? |
| Commission by Rule    | Which commission rules generated commission?               |
| Commission by Invoice | How much commission was generated from each Sales Invoice? |
| Commission by Date    | How did commission activity change over a date range?      |

All reports use Commission Ledger records as their source.

## Commission Summary

The **Commission Summary** report provides an overall view of commission activity.

### When to Use It

Use this report when you want a high-level summary of commissions for a company and date range.

It is useful for:

- reviewing total commission activity
- checking commission amounts before statement generation
- investigating commission totals
- getting a quick overview of calculated commissions

### Filters

The report supports:

- Company
- From Date
- To Date
- Commission Payee
- Commission Plan
- Commission Rule
- Sales Invoice

Optional filters can be used to narrow the result set.

## Commission by Payee

The **Commission by Payee** report groups commission activity by Commission Payee.

### When to Use It

Use this report when you want to understand how much commission has been generated for individual payees.

It is useful for:

- reviewing salesperson commission activity
- comparing commission amounts between payees
- investigating an individual payee's commission
- preparing for statement review

### Filters

The report supports:

- Company
- From Date
- To Date
- Commission Payee
- Commission Plan
- Commission Rule
- Sales Invoice

Use the Commission Payee filter to focus the report on a specific recipient.

## Choosing the Right Report

Use the report that matches the question you are trying to answer:

| Question                                      | Report                |
| --------------------------------------------- | --------------------- |
| How much commission was generated overall?    | Commission Summary    |
| How much did a particular payee earn?         | Commission by Payee   |
| How much commission came from a plan?         | Commission by Plan    |
| Which rule generated a commission?            | Commission by Rule    |
| Which invoice generated the commission?       | Commission by Invoice |
| How did commission activity change over time? | Commission by Date    |

## Reports and the Commission Ledger

Commission reports are based on Commission Ledger records.

The Commission Ledger stores the historical result of a commission calculation, including information such as:

- Sales Invoice
- Commission Payee
- Commission Rule
- Commission Plan
- Calculation Method
- Rate
- Base Amount
- Commission Amount
- Transaction Date
- Status

Because the ledger records the calculated commission, reports can be used to investigate commission activity without recalculating historical transactions.

## Filtering Reports

Start with the broadest useful date range and company.

Then use optional filters when investigating a specific area.

For example:

1. Select the Company.
2. Select the From Date and To Date.
3. Review the report results.
4. Add a Commission Payee, Plan, Rule, or Sales Invoice filter if you need a narrower view.

This approach makes it easier to move from an overall commission view to a specific transaction or configuration.

## Reports During Commission Review

Reports can be useful at different stages of the commission lifecycle.

### Before Statement Generation

Use reports to review calculated Commission Ledger entries before grouping them into a Commission Statement.

### During Statement Review

Use payee, plan, rule, and invoice reports to investigate the entries included in commission activity.

### After Posting

Use reports to analyze finalized commission activity and understand historical commission performance.

## Troubleshooting Commission Amounts

If a commission amount looks unexpected:

1. Use **Commission by Invoice** to identify the commission generated from the Sales Invoice.
2. Use **Commission by Payee** to verify the recipient.
3. Use **Commission by Rule** to identify the rule responsible.
4. Use **Commission by Plan** to identify the selected plan.
5. Open the related Commission Ledger entry to inspect the calculation details.

This provides a path from an aggregated report result back to the historical commission calculation.

## Best Practices

- Use a clear date range when running reports.
- Select the correct Company when working with multiple companies.
- Use payee, plan, rule, or invoice filters when investigating specific commission activity.
- Use Commission by Invoice when tracing a commission back to its source transaction.
- Use Commission by Payee when reviewing individual commission activity.
- Use Commission by Date when looking for changes in commission activity over time.
- Treat the Commission Ledger as the historical source for commission reporting.
